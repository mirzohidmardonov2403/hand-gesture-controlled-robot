# Hand Gesture Controlled Robot

A real-time robotic control system using computer vision and hand gesture recognition.

## Overview

This project demonstrates a robot controlled through hand gestures using computer vision and embedded systems. The system detects hand movements, interprets predefined gestures, and sends control commands to the robot.

## Features

- Real-time hand gesture recognition
- Computer vision-based control
- Wireless communication
- Embedded robot control
- Real-time motor control
- Gesture-based movement commands

## Technologies

- Python
- OpenCV
- Computer Vision
- ESP32 / ESP32-CAM
- C++
- Embedded Systems

## System Architecture

Camera → Hand Detection → Gesture Recognition → Wireless Communication → ESP32 → Motor Driver → Robot
